exists for this project, therefore no detection-quality metric exists, and none is claimed.**

scaffolding). It proves the plumbing works; it proves nothing about accuracy.

## What was actually executed and measured

Synthetic fixture = `tools/dataset/tests/fixtures/synthetic_corpus/sample.jsonl`
(24 rows / 6 fictional players / 12+12 labels; generated by a seeded generator, committed
with a warning banner). Results on it, reproduced verbatim:

1. **Validation/ingest/split/evaluate tooling** — `python3 -m unittest discover -s tools/dataset/tests`:
   **24 tests, all passing** (schema/golden-hash equality with the Java side, rejection rules,
   dedup counting, deterministic group split, leakage detection incl. the `split --check` CLI,
   hand-computed confusion matrix, INSUFFICIENT_DATA gate, manifest round-trip/tamper, ingest CLI).
2. **XGBoost training smoke + ONNX export + numerical parity** (`/tmp` scratch venv, not committed):
   5-tree/depth-2 model trained with seed 1337 on a group-by-player split (16 train / 8 val /
   0 test — the fixture is too small for a complete group split); export produced a single-output
   `anomaly_score` ONNX model; **onnxruntime CPU vs xgboost `predict_proba` max |Δ| =
   2.98e-08** (tolerance 1e-4) — recorded in the smoke run's `parity.json`. The test split was
   empty and is reported as such (`{"error": "empty split after group-by-player assignment"}`);
   no metric is invented to fill it.
3. **Java ↔ Python cross-implementation locks**: schema SHA-256 constant
   `2f2b0a3eb4563552b5c995c285f7179ce34490c450c46b63e9dbc022916ee688` asserted equal in both
   `SchemaHashGoldenTest` (Java) and `test_pipeline.py` (Python). Manifest SHA-256 of the artifact
   verifies in both implementations.
4. **Java ONNX adapter happy path executed for the first time** — `OnnxRuntimeEndToEndTest` loads
   a committed SYNTHETIC fixture model (`src/test/resources/onnx/synthetic-fixture-xgb-tiny-0001/`,
   1106 bytes, trained on item 2's corpus) with a real `com.microsoft.onnxruntime` test-only
   dependency and asserts: artifact loads via `ModelRegistry`, Java-side score equals the Python
   onnxruntime reference (0.12896090745925903 legit-row, 0.855519711971283 cheat-row) within
   1e-4, cheat-row > legit-row, deterministic repeat calls. **These assertions validate the runtime
   contract only. The fixture model MUST NOT be loaded in production.**
5. **Inference benchmark** — `AiInferenceBenchmarkTest` scores 10k synthetic feature vectors with
   a seeded synthetic forest and asserts a deliberately generous bound (< 10 s total); prints
   min/median/p99/max. **This is a correctness tripwire, not a production benchmark;** real
   deployment latency is **NOT MEASURED**.

Nothing above constitutes evidence that VigilAC detects cheats.

## Minimum gates before any number may be reported

`corpus_gates()` requires ≥ 200 usable rows, ≥ 50 `CHEAT_VERIFIED` (CONTROLLED_LAB or
MODERATOR_REVIEW, confidence ≥ 0.8), ≥ 50 `LEGITIMATE`; group-by-player split; otherwise
`evaluate.py`/`train_supervised.py` exit `INSUFFICIENT_DATA`. Reports include Wilson 95%
intervals. `SUSPICIOUS` rows never enter evaluation. Cross-version and per-category breakdowns
are emitted by `evaluate.py` only after the gates pass.

## What would make this page non-embarrassing

1. A consented, licensed capture program (see `docs/DATASET.md` §2/§3) with recorded provenance.
2. ≥ 50 lab-verified cheat windows across ≥ 2 cheat categories and ≥ 2 input categories,
   plus ≥ 50 curated legitimate windows from ≥ 3 server versions.
3. A registered training run: corpus SHA-256, `splits.json`, resolved `train.config.json`, seed,
   artifact SHA-256, evaluation report with CIs — all committed or externally archived by hash.
4. A production pilot with `ai.enabled=true`, shadow-only, with false-positive review of every
   MEDIUM/HIGH assessment over ≥ 4 weeks before any tuning discussion.
5. Revision of `REAL_CLIENT_VALIDATION` from BLOCKED → executed (never → maybe).

Until then: every accuracy claim is absent from documentation, and the deterministic engine
remains the only detection system with any evidentiary standing.
